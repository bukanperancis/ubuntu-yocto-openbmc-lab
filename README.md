# Ubuntu, Yocto & OpenBMC Lab

A hands-on learning repository documenting my journey into Linux development,
Meson, Yocto Project, BitBake, and OpenBMC.

## Objectives

- Strengthen Linux and Ubuntu development fundamentals.
- Learn C/C++ build systems, particularly Meson and Ninja.
- Understand Yocto Project, Poky, BitBake, recipes, and layers.
- Build, package, and deploy applications into embedded Linux images.
- Explore systemd, D-Bus, and Linux services.
- Develop foundational knowledge of OpenBMC architecture and BMC development.

## Repository Structure

| Directory | Description |
|---|---|
| `01-ubuntu-fundamentals` | Linux and Ubuntu development fundamentals |
| `02-meson-fundamentals` | Meson build system and C++ projects |
| `03-yocto-fundamentals` | Yocto, BitBake, and custom layers |
| `04-yocto-meson-integration` | Integrating Meson projects into Yocto |
| `05-qemu-linux-image` | Embedded Linux image building and emulation |
| `06-systemd-journald` | Linux services and logging |
| `07-dbus` | Inter-process communication |
| `08-openbmc` | OpenBMC architecture and component exploration |

## Learning Approach

Projects are developed incrementally, tested locally, and tracked using Git.
